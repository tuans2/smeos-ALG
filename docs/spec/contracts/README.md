# Contracts
Nguồn sự thật cho định dạng trao đổi giữa các hệ thống. Mọi thay đổi theo SemVer (REQ-VER-001, REQ-VER-004).
- `event-envelope.schema.json` — phong bì sự kiện chuẩn (REQ-CON-015).
- `openapi/integration.openapi.json` — OpenAPI 3.1 của Integration API `/api/v1/integration/*` (07/11/2026). **Tệp sinh ra, không sửa tay**: nguồn là lược đồ zod ở `src/modules/integration/contracts/` (`npm run gen:openapi`); `tests/unit/integration/integration-openapi.test.ts` đỏ khi tệp cũ, `tests/tenant/integration-contract.test.ts` kiểm phản hồi thật khớp lược đồ.
- `openapi/public.openapi.json` — OpenAPI 3.1 của 42 operation công khai `/api/v1/public/*` (07/11/2026). **Tệp sinh ra, không sửa tay**: nguồn ở `src/app/api/v1/public/_contracts/` (`npm run gen:openapi`); `tests/unit/public/public-openapi.test.ts` đỏ khi tệp cũ hoặc có route chưa khai, `tests/tenant/public-contract-*.test.ts` kiểm phản hồi thật. Không công bố cho đối tác.
- `openapi/platform.openapi.json` — OpenAPI 3.1 của 70 operation Console Vận hành Nền tảng `/api/v1/platform/*` (07/11/2026). **Tệp sinh ra, không sửa tay**: nguồn ở `src/app/api/v1/platform/_contracts/` (`npm run gen:openapi`); `tests/unit/platform/platform-openapi.test.ts` đỏ khi tệp cũ, có route chưa khai operation hoặc mã năng lực lệch đặc tả 06; `tests/platform/platform-contract-*.test.ts` kiểm phản hồi thật. Nội bộ, không công bố.
- `openapi/internal.openapi.json` — OpenAPI 3.1 nội bộ của API tiệm (giao diện SMEOS gọi), phủ dần theo nhóm (PO 07/11/2026). Đợt nhóm lõi (08/11/2026): 94 operation (74 route) của đơn hàng `/orders/*`, báo giá `/quotations/*`, sản phẩm `/products/*`, khách hàng `/crm/*`, thành viên `/members/*`, tổ chức `/organizations/*` + `/organization/brand`, xác thực `/auth/*`. Đợt Thẻ chào (08/11/2026): thêm 85 operation (66 route) `/greeting-card/*` — tổng 179 operation. **Tệp sinh ra, không sửa tay**: nguồn ở `src/app/api/v1/_contracts/` (`npm run gen:openapi`); `tests/unit/architecture/internal-openapi.test.ts` đỏ khi tệp cũ, khi route trong nhóm đã phủ (`INTERNAL_COVERED_PREFIXES`) chưa khai operation hoặc mã năng lực lệch đặc tả 06; `tests/tenant/internal-contract-*.test.ts` kiểm phản hồi thật. Nội bộ, không công bố.
